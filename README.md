# SiriDhanyaHub

SriDhanya Hub is an Android application developed using Kotlin in Android Studio.

It helps users:
•⁠  ⁠View millet market prices
•⁠  ⁠Explore healthy millet recipes
•⁠  ⁠Learn millet nutrition benefits
•⁠  ⁠Buy millet products

---

## Technologies Used

•⁠  ⁠Kotlin
•⁠  ⁠Android Studio
•⁠  ⁠Retrofit
•⁠  ⁠RecyclerView
•⁠  ⁠MockAPI
•⁠  ⁠Material Design

---

## Features

•⁠  ⁠User Login & Registration
•⁠  ⁠Home Dashboard
•⁠  ⁠Live Millet Market Prices
•⁠  ⁠Health Benefits Section
•⁠  ⁠Millet Recipes
•⁠  ⁠Buy Products Page
